# PSR3 PC App

Тёмное приложение-компаньон для самодельной PSR3.

## Что уже реализовано

- подключение к ESP32 по адресу `http://192.168.4.1`;
- Mock Mode для проверки интерфейса без ESP32;
- после успешного подключения — чёрный переход 1.5 секунды;
- четыре нижних раздела: Главная, PSR Store, Библиотека, Профиль;
- PSR Store в тёмном стиле: все игры бесплатные, рейтинг 13+, описание игры находится внизу страницы;
- кнопка «Скачать» не скачивает файл на ПК: она передаёт Game ID на ESP32;
- визуальная установка каждой игры длится не меньше 20 секунд;
- библиотека с вкладками «Все» и «Установленные»;
- профиль Максим Волошин, SONY, аватар по двойному нажатию, шкала уровня, PSR3 (Playstation 3 Remale), трофеи и четыре установленные игры.

## Протокол ESP32

Проверка соединения:

`GET http://192.168.4.1/status`

Выбор игры:

`POST http://192.168.4.1/game?id=1&name=MP3Dtest`

Приложение также отправляет JSON:

`{"gameId":1,"gameName":"MP3Dtest"}`

ESP32 должна ответить HTTP 2xx. При старте визуальной установки Game ID уже должен быть записан на ESP32.

## Windows EXE

GitHub Actions собирает release-папку Windows. Нужна вся папка артефакта, а не только .exe:

Actions -> Build PSR3 Windows -> последний успешный запуск -> Artifacts -> PSR3-Windows.
