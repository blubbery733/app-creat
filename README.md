# PSR3 Android App

Android-приложение-компаньон для PSR3.

## Интерфейс

- основной акцент — зелёный;
- большой баннер MP3Dtest в разделе «Новинки» остаётся отдельным с синим градиентом;
- нижняя навигация состоит из четырёх квадратных кнопок;
- разделы: Главная, PSR Store, Библиотека, Профиль;
- PSR Store использует иконки для игр и информационных блоков;
- все игры бесплатные и имеют рейтинг 13+;
- описание игры расположено внизу страницы игры.

## Установка игр

Кнопка «Скачать» не загружает файл игры на телефон.

Она передаёт Game ID на ESP32:

`POST http://192.168.4.1/game?id=1&name=MP3Dtest`

и JSON:

`{"gameId":1,"gameName":"MP3Dtest"}`

После ответа ESP32 приложение показывает процесс установки.

Тестовые времена установки:
- MP3Dtest — 46 секунд;
- Neon Track — 1 минута;
- Cube Runner — 1 минута 30 секунд;
- ReGame Arena — 2 минуты;
- Sky Lines Beta — 3 минуты;
- Pixel Drift — 5 минут.

Минимум — 46 секунд, максимум — 5 минут.

## Звуки

Используются:
- `assets/audio/install.mp3` — начало установки и нажатия навигации;
- `assets/audio/notification.mp3` — успешное действие;
- `assets/audio/error.mp3` — ошибка.

## Профиль

- SONY;
- Максим Волошин;
- PSR3 (Playstation 3 Remale);
- шкала уровня;
- трофеи;
- список из четырёх установленных игр;
- двойное нажатие на аватар открывает галерею Android;
- выбранная фотография копируется в данные приложения и сохраняется между запусками.
